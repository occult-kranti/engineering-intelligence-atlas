Project Mode

Run a small text-only research squad (Director → Research → Build → Review) against a goal, on-device, using your own OpenAI or Anthropic API key. Keys are encrypted with the Android Keystore; provider calls are made natively to the official API hosts only.

Open Project Mode

Connect Runtime

Enter the address of your own running Research Director server. The remote page opens in this app's WebView and is responsible for sign-in.

HTTPS is required. Plain HTTP is accepted only for localhost development (localhost, 127.0.0.1, 10.0.2.2).

Privacy & costs

  • The launcher itself stores only the runtime URL you enter (Capacitor Preferences / local app storage). Project mode additionally stores API keys — encrypted with the Android Keystore, ciphertext only in app-private storage — plus non-secret project data (goals, squad notes, budgets, run logs, text artifacts).
  • The online Director is a remote web app. Any cloud or LLM/API usage happens on the server you connect to, requires that server to be running and authenticated, and can incur charges billed by that server's providers. Project mode instead calls api.openai.com / api.anthropic.com directly from native code with your key; those calls are billed by the provider to you.
  • Links that leave the runtime or atlas open in your system browser.
