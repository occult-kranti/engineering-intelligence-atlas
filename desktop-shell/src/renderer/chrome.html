Local Projects

Run text-only specialist squads (Director / Research / Build / Review) on your own OpenAI or Anthropic key — or a local Ollama — with hard token, time, and dollar budgets. Keys stay encrypted in your OS keychain; prompts go only to the provider you choose.

Privacy & billing

  • Offline atlas & System & Models: fully local. No data leaves your device; no charges.
  • Online runtime: your projects, prompts, and files are processed by the hosted Director service under its own terms; usage may be billed by that service. The desktop shell never sees your credentials.
  • Model downloads: files are fetched from Hugging Face over HTTPS into this device only. Models are never executed by this shell.
  • Job log: local JSONL log of downloads/venvs under the app data directory. No secrets.
  • Local Projects: prompts and generated text go directly from this device to the provider you select (OpenAI / Anthropic) or to your local Ollama. Providers bill your own key per their terms. Your budgets (tokens / minutes / USD) are hard stops. API keys are stored only as OS-keychain-encrypted blobs under the app data directory and are never displayed or logged.

Local Projects

API keys

Keys are encrypted with your OS keychain (Electron safeStorage) and stored only as encrypted blobs under the app data directory. They are used only for direct API calls from this device to the selected provider, are never shown again after entry (not even a last4), and never appear in logs, events, or artifacts. Revoke deletes the encrypted blob. See SECURITY.md for the threat model (rooted devices, unlocked keyrings, your responsibilities).

Ollama (optional, local only)

Detects an Ollama server you already started at http://127.0.0.1:11434 and lists the models you already downloaded. This shell never installs or starts Ollama, never pulls models, and never contacts remote Ollama hosts.

System information

Virtual environments

Creates an isolated Python venv under the app data directory (userData/venvs/<name>) using the detected Python 3. The shell never activates environments and never runs repo or model code.

Model catalog (reviewed)

Only models reviewed into models.catalog.json appear here. Downloads require your confirmation, are pinned to a commit, land under userData/models, and are never executed.
