# Shared resources across Daftar skills

All 15 Daftar repository skills now include a bounded resource-selection step and a packaged, self-contained `references/resource_use.md`. The existing domain workflows and game-reconstruction gates remain intact; the gaming skill's procedural Three.js path is included in the refreshed archive and public mirror.

## Resulting behavior

Each skill starts with the public reference packet supplied to the task. Inside a Daftar checkout, it can run the existing offline router with its exact skill ID and task terms; outside that checkout it uses provided sources or authorized primary-source discovery. It does not assume the router or any external software is installed.

The instructions require source relevance, access and license checks, version or revision identity, exact reading depth, evidence limitations and actual tests. They distinguish books/papers from freely redistributable content, metadata hashes from artifact hashes, author-reported results from reproduction, and software descriptions from installed capabilities. SOTA claims must name a dated task and evaluation basis. Private company documents retain their existing scope.

The resource procedure grants no new capability or budget and does not fetch, install, run or purchase anything by itself. It reuses existing valid task authorization and asks only when necessary authority is missing. A missing reference remains an explicit evidence gap.
