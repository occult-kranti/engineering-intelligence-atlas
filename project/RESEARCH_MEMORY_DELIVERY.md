## Memory behavior and boundaries

- Authorization, company identity, current validity, corrections and quarantine
  are applied before lexical statistics and graph propagation. Parent/sibling
  companies do not expand private retrieval. Explicit sharing still needs the
  existing grant and active source evidence.
- Facts, decisions, questions and procedures use the existing durable native
  knowledge command. A same-company correction preserves the older record while
  retiring it from current retrieval. Malformed or unsupported typed envelopes
  are quarantined. A correction that was never active cannot retire earlier
  valid evidence.
- The same freshness filter covers graph retrieval, legacy recent-knowledge
  context and explicitly transferred evidence. This prevents an expired note
  from re-entering the prompt through an older path.
- Retrieval uses BM25 seeds, bounded personalized PageRank and reciprocal-rank
  fusion. Ranking selects candidates; it does not certify truth or answerability.
  Donna is told to report absent or unresolved evidence when candidates do not
  answer the question.
- Public snapshots use content hashes and atomic pointer replacement. Cache keys
  include the source snapshot, algorithm, policy, scope, query/bounds and temporal
  eligibility. The local file store is not advertised as an authenticated server
  or a power-loss-proof transactional database.
- Private live company records are not inputs to the public study build. The
  public web preview is read-only. Browser fixtures exercise a synthetic bridge,
  not native database persistence or real provider work.
- Current organization projection is not a historical reconstruction of every
  mutable field. Typed note validity and corrections have explicit time rules.

## Measured retrieval result

The [fixed evaluation](../projects/research-memory-atlas/evaluation/README.md)
retains questions, answer labels, raw ranks, timings, controls and source/software
hashes. Parameters were not tuned after observing the results.

| Setting | Success@6, 12 answerable questions | Mean reciprocal rank |
|---|---:|---:|
| Lexical-only (`alpha=0`) | 11/12 | 0.854167 |
| Default graph propagation (`alpha=0.85`) | 11/12 | 0.819444 |

Graph propagation did **not** improve this authored sanity set. Both settings
missed a relational Fourier-prerequisite question. A private-payroll absent-answer
control retrieved related public candidates: an abstention failure, not disclosure
of private records. Empty and out-of-vocabulary controls returned no match. These
results are not a held-out benchmark or a general SOTA claim.

For one local query, five uncached samples had a **138.014 ms** median and five
warm result-cache samples a **61.132 ms** median, with identical result IDs. No
provider was called and no provider token/cost saving was measured.
