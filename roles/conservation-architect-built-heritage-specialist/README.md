# Conservation Architect / Built-Heritage Specialist

**Function:** Architecture & heritage

**Mission:** Evaluate and intervene in heritage assets with significance, evidence, and minimal harm

## Accountable outputs
Significance assessment; documentation; conservation plan; reversible interventions; provenance/community record

## Core skills
Architectural history; materials/pathology; conservation charters; documentation; stakeholder engagement

## Senior-scope differentiator
Leads complex conservation methodology and independent ethical review

## Interfaces
Custodians; communities; archaeologists; architects; regulators
