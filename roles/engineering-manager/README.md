# Engineering Manager

**Function:** Leadership & governance

**Mission:** Create a healthy team that delivers and operates valuable software

## Accountable outputs
Capacity/roadmap; hiring; performance/growth; delivery system; incident/process ownership

## Core skills
People leadership; technical decision brokerage; planning; feedback; risk management

## Senior-scope differentiator
Improves team system and develops senior owners rather than personally making every decision

## Interfaces
PM; tech lead; designer; QA; SRE; security

## Public reference
https://sfia-online.org/en/sfia-9

Reference role charter for organization design and hiring; not a claim of a current vacancy or a universal job-title mapping.
