# Cloud Security Engineer

**Function:** Security engineering

**Mission:** Create secure-by-default cloud identities, configurations, guardrails, and detection

## Accountable outputs
Cloud baselines; IAM policy; IaC controls; posture metrics; incident support

## Core skills
AWS/Azure/GCP; IAM; networking; IaC; cloud telemetry; scripting

## Senior-scope differentiator
Owns organization-wide cloud security patterns and exception risk

## Interfaces
Cloud; IAM; AppSec; SOC; platform; compliance
