# Performance Engineer

**Function:** Quality engineering

**Mission:** Find and prevent latency, throughput, resource, and scalability failures

## Accountable outputs
Performance model/budgets; profiles; load tests; capacity recommendations; regression gates

## Core skills
Profiling; networking; runtimes; databases; statistics; field/lab measurement

## Senior-scope differentiator
Leads cross-system performance and capacity strategy

## Interfaces
Backend; frontend; SRE; data; platform; product
