# Data Scientist

**Function:** Data & analytics

**Mission:** Improve decisions through statistical analysis, modeling, and experiments

## Accountable outputs
Analyses; experiment designs/readouts; models; decision narratives; reusable datasets

## Core skills
SQL; statistics; causal inference; Python/R; visualization; communication

## Senior-scope differentiator
Leads ambiguous decision problems and measurement strategy

## Interfaces
Product; research; data engineering; design; leadership

## Public reference
https://sfia-online.org/en/sfia-9
