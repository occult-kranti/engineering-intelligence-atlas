# Community / Developer Relations Manager

**Function:** Community & developer relations

**Mission:** Build reciprocal learning, contribution, support, and advocacy relationships with users and developers

## Accountable outputs
Community programs; events/content; contribution pathways; feedback synthesis; health metrics

## Core skills
Communication; technical empathy; facilitation; moderation; accessibility; program evaluation

## Senior-scope differentiator
Owns regional/domain community strategy and durable contributor leadership

## Interfaces
Engineering; product; support; marketing; research; legal
