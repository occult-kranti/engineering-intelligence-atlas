# Analytics Engineer

**Function:** Data & analytics

**Mission:** Transform raw data into tested, semantic, decision-ready datasets

## Accountable outputs
Versioned transformations; metrics/semantic layer; tests; documentation; dashboards

## Core skills
SQL; dimensional modeling; dbt-style workflows; metrics governance; communication

## Senior-scope differentiator
Owns metric semantics and analytics engineering standards

## Interfaces
