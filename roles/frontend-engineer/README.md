# Frontend Engineer

**Function:** Software engineering

**Mission:** Build and operate accessible, performant browser experiences

## Accountable outputs
Semantic UI; components; tests; performance budgets; telemetry; accessibility evidence

## Core skills
HTML/CSS/JavaScript/TypeScript; framework literacy; state/data; accessibility; testing

## Senior-scope differentiator
Sets web architecture, design-system, performance, and accessibility direction

## Interfaces
Design; backend; QA; accessibility; product

## Public reference
https://www.w3.org/WAI/planning/arrm/

Reference role charter for organization design and hiring; not a claim of a current vacancy or a universal job-title mapping.

## Collaboration note

When this role is composed as a specialist under the agent-research-director, it follows the shared [skill collaboration protocol](../../organization/skill_collaboration_protocol.md) (typed artifact handoffs, shared budgets and deadlines, no busy waiting, cancellation, and approval gates).
