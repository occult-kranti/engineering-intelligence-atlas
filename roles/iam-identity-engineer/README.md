# IAM / Identity Engineer

**Function:** Security engineering

**Mission:** Engineer authentication, authorization, identity lifecycle, and least privilege

## Accountable outputs
Identity architecture; SSO/OIDC/OAuth; RBAC/ABAC; secrets/workload identity; audits

## Core skills
IAM protocols; directories; PKI; policy; automation; access-risk analysis

## Senior-scope differentiator
Sets identity architecture and high-assurance access strategy

## Interfaces
Security; IT; cloud; application; privacy; support

https://niccs.cisa.gov/tools/nice-framework
