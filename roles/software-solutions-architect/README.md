# Software / Solutions Architect

**Function:** Architecture & technical leadership

**Mission:** Translate needs and constraints into evolvable system and integration decisions

## Accountable outputs
Reference architecture; NFRs; ADRs; integration contracts; migration/fitness review

## Core skills
Domain modeling; distributed systems; security; data; cost; communication

## Senior-scope differentiator
Guides architecture across domains and governs by evidence rather than approval theater

## Interfaces
Product; engineering; platform; security; data; SRE
