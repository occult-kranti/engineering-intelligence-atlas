# Incident Responder

**Function:** Security operations

**Mission:** Coordinate and execute containment, eradication, recovery, and learning

## Accountable outputs
Incident command; timeline; containment evidence; communications; post-incident actions

## Core skills
IR process; forensics; systems; decision-making; legal/comms interfaces

## Senior-scope differentiator
Leads severe/cross-org incidents and resilience improvements

## Interfaces
SOC; DFIR; legal; executives; engineering; support

## Public reference
https://niccs.cisa.gov/tools/nice-framework
