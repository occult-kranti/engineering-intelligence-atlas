# Finance / Operations Analyst

**Function:** Finance & operations

**Mission:** Make budget, unit-cost, procurement, capacity, and operating constraints visible and reliable

## Accountable outputs
Budget/scenarios; cost model; vendor/procurement records; operating dashboard; variance analysis

## Core skills
Finance/accounting literacy; spreadsheets/data; forecasting; controls; communication

## Senior-scope differentiator
Owns organization-level resource allocation analysis and financial controls

## Interfaces
Leadership; engineering; product; legal; procurement; people
