# Technical Game Designer

**Function:** Game design

**Mission:** Bridge design intent and hands-on implementation through playable technical prototypes

## Accountable outputs
Mechanic/system implementation; technical design docs; Blueprint/script prototypes; tuning tools

## Core skills
Engine literacy; scripting/Blueprints; system design; debugging; design communication

## Senior-scope differentiator
Leads complex prototype-to-production systems and technical design standards

## Interfaces
Gameplay; design; tools; UX; QA; production
