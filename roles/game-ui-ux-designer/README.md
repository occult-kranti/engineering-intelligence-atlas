# Game UI/UX Designer

**Function:** Player experience

**Mission:** Make game mechanics, navigation, status, and actions understandable and low-friction

## Accountable outputs
Player flows; HUD/UI states; prototypes; accessibility annotations; usability findings

## Core skills
Interaction/visual design; game literacy; prototyping; console/PC/mobile input; accessibility

## Senior-scope differentiator
Owns portfolio/title experience cohesion and cross-disciplinary UX leadership

## Interfaces
Game design; UI engineering; research; accessibility; production

## Public reference
https://www.w3.org/WAI/planning/arrm/

Reference role charter for organization design and hiring; not a claim of a current vacancy or a universal job-title mapping.

When this role is composed as a specialist under the agent-research-director, it follows the shared [skill collaboration protocol](../../organization/skill_collaboration_protocol.md) (typed artifact handoffs, shared budgets and deadlines, no busy waiting, cancellation, and approval gates).
