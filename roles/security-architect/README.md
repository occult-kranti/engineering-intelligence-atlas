# Security Architect

**Function:** Security engineering

**Mission:** Design secure system boundaries and reusable security patterns

## Accountable outputs
Threat architecture; control patterns; security ADRs; assurance review; exceptions

## Core skills
Security architecture; cloud/application/data; IAM; cryptography; tradeoff writing

## Senior-scope differentiator
Sets cross-org security architecture and high-risk exception direction

## Interfaces
Engineering; CISO; AppSec; cloud; privacy; SRE
