# Brand / Communications Designer

**Function:** Brand & communications

**Mission:** Create coherent, truthful visual and verbal identity across products and campaigns

## Accountable outputs
Brand system; messaging hierarchy; design assets; editorial guidelines; accessibility and usage review

## Core skills
Visual/verbal design; typography; audience research; content design; brand governance

## Senior-scope differentiator
Owns organization-wide identity system and cross-channel coherence

## Interfaces
Marketing; product; design; leadership; legal; community

https://sfia-online.org/en/sfia-9
