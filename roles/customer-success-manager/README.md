# Customer Success Manager

**Function:** Customer outcomes

**Mission:** Help customers achieve declared outcomes and feed adoption barriers back into the company

## Accountable outputs
Success plans; onboarding; outcome reviews; health/risk signals; renewal/expansion evidence

## Core skills
Customer/domain knowledge; project management; communication; analytics; problem solving

## Senior-scope differentiator
Owns portfolio-level customer outcomes and systemic adoption improvements

## Interfaces
Sales; product; support; engineering; research; marketing
