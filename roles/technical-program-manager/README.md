# Technical Program Manager

**Function:** Product & program

**Mission:** Drive complex cross-team programs and dependencies to completion

## Accountable outputs
Dependency/risk register; integrated plan; decision log; launch coordination

## Core skills
Systems thinking; dependency management; communication; technical fluency

## Senior-scope differentiator
Resolves multi-org dependencies and establishes program governance

## Interfaces
PM; EM; architects; QA; release; security

## Public reference
https://sfia-online.org/en/sfia-9

Reference role charter for organization design and hiring; not a claim of a current vacancy or a universal job-title mapping.
