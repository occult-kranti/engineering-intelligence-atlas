# Agent Skill Engineer / Evaluator

**Function:** Agent governance & research

**Mission:** Design, test, secure, version, and measure reusable skills and plugin/agent workflows

## Accountable outputs
Skill specs; eval cases; permission manifest; provenance/license review; regression/security reports

## Core skills
Prompt/workflow design; software testing; agent evaluation; supply-chain security; documentation

## Senior-scope differentiator
Owns organizational skill quality, portability, and lifecycle governance

## Interfaces
Agent platform; security; domain experts; product; compliance

## Public reference
https://agentskills.io/specification

Reference role charter for organization design and hiring; not a claim of a current vacancy or a universal job-title mapping.

## Collaboration note

When this role is composed as a specialist under the agent-research-director, it follows the shared [skill collaboration protocol](../../organization/skill_collaboration_protocol.md) (typed artifact handoffs, shared budgets and deadlines, no busy waiting, cancellation, and approval gates). This does not change the role charter above.
