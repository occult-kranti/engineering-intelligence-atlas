# DFIR / Forensics Engineer

**Function:** Security operations

**Mission:** Acquire, preserve, examine, and report digital evidence with defensible provenance

## Accountable outputs
Custody log; verified images/copies; timelines; analysis report; retained evidence

## Core skills
File systems; memory; logs; hashing; chain of custody; tool validation

## Senior-scope differentiator
Leads complex forensic methodology and evidence-quality assurance

## Interfaces
IR; legal; HR; SOC; privacy; reverse engineering

## Public reference
https://nvlpubs.nist.gov/nistpubs/legacy/sp/nistspecialpublication800-86.pdf
