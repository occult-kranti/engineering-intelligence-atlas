# Detection Engineer

**Function:** Security operations

**Mission:** Convert threat knowledge and telemetry into tested, maintainable detections

## Accountable outputs
Detection-as-code; test cases; coverage map; tuning; response handoff

## Core skills
Logs/query languages; attacker behavior; scripting; CI; false-positive analysis

## Senior-scope differentiator
Owns detection strategy, coverage, and measurement across environments

## Interfaces
SOC; threat intel; IR; cloud; data; engineering

## Public reference
https://niccs.cisa.gov/tools/nice-framework

Reference role charter for organization design and hiring; not a claim of a current vacancy or a universal job-title mapping.
