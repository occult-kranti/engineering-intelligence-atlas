# Application / Product Security Engineer

**Function:** Security engineering

**Mission:** Integrate threat modeling, secure design, verification, and remediation into products

## Accountable outputs
Threat models; code/design review; ASVS tests; vulnerability triage; developer guidance

## Core skills
Secure coding; web/mobile; OWASP; SAST/DAST/SCA; APIs; communication

## Senior-scope differentiator
Leads product security strategy and high-risk design partnerships

## Interfaces
Product; engineering; QA; platform; privacy

## Public reference
https://owasp.org/www-project-application-security-verification-standard/
