# Product Manager

**Function:** Product & program

**Mission:** Own problem selection, customer value, viability, and outcome priorities

## Accountable outputs
Problem narrative/PRD; prioritization; outcome metrics; discovery plan; launch tradeoffs

## Core skills
Customer/domain knowledge; business judgment; analytics; prioritization; writing

## Senior-scope differentiator
Handles portfolio ambiguity and aligns multiple value streams

## Interfaces
Design; tech lead; EM; data; research; go-to-market

## Public reference
https://sfia-online.org/en/sfia-9

Reference role charter for organization design and hiring; not a claim of a current vacancy or a universal job-title mapping.
