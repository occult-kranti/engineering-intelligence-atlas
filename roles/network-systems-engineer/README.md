# Network / Systems Engineer

**Function:** Platform & infrastructure

**Mission:** Build and operate dependable network and operating-system foundations

## Accountable outputs
Network/system designs; DNS/LB/connectivity; automation; monitoring; recovery evidence

## Core skills
TCP/IP; DNS; TLS; Linux; routing; load balancing; troubleshooting; security

## Senior-scope differentiator
Leads complex network/system architecture and failure-domain design

## Interfaces
Cloud; SRE; security; platform; backend
