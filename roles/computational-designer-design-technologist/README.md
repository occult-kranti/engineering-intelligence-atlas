# Computational Designer / Design Technologist

**Function:** Architecture & computation

**Mission:** Apply parametric, algorithmic, and data-driven methods to architectural design and delivery

## Accountable outputs
Parametric models; scripts/plugins; design options; geometric rationalization; validation

## Core skills
Grasshopper/Rhino or equivalent; Python/C#; geometry; BIM; fabrication; communication

## Senior-scope differentiator
Owns practice-wide computational design standards and difficult geometry

## Interfaces
Architecture; fabrication; BIM; engineering; software

https://www.cgal.org/
