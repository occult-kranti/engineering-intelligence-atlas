# Architect / Architectural Designer

**Function:** Architecture

**Mission:** Develop safe, functional, contextual, and code-aware designs from brief through delivery

## Accountable outputs
Brief/site analysis; concepts; drawings/models; coordination; specifications; review evidence

## Core skills
Design; building systems; codes; sustainability; communication; professional judgment

## Senior-scope differentiator
Owns complex projects and multidisciplinary technical/creative direction

## Interfaces
Clients; engineering; planning; construction; heritage; BIM
