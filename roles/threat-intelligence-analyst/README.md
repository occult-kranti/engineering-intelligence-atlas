# Threat Intelligence Analyst

**Function:** Security operations

**Mission:** Produce decision-relevant intelligence from sourced, evaluated evidence

## Accountable outputs
Collection plan; source evaluation; actor/campaign analysis; briefs; detection leads

## Core skills
OSINT; analytical tradecraft; link analysis; writing; languages/domain context

## Senior-scope differentiator
Sets intelligence priorities and strategic threat assessments

## Interfaces
SOC; detection; IR; leadership; game security

## Public reference
https://niccs.cisa.gov/tools/nice-framework

Reference role charter for organization design and hiring; not a claim of a current vacancy or a universal job-title mapping.

## Collaboration note

When this role is composed as a specialist under the agent-research-director, it follows the shared [skill collaboration protocol](../../organization/skill_collaboration_protocol.md) (typed artifact handoffs, shared budgets and deadlines, no busy waiting, cancellation, and approval gates). This does not change the role charter above.
