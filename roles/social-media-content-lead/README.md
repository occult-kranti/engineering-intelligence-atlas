# Social Media / Content Lead

**Function:** Marketing & growth

**Mission:** Plan and publish accurate, useful, audience-appropriate content with accountable review

## Accountable outputs
Editorial strategy; content calendar; sourced assets; channel adaptations; response/learning log

## Core skills
Writing; audience research; platform literacy; visual/verbal judgment; accessibility; crisis response

## Senior-scope differentiator
Owns multi-channel editorial quality, reputation, and evidence-based learning

## Interfaces
Marketing; design; research; legal; community; product
