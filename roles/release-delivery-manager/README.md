# Release / Delivery Manager

**Function:** Product & program

**Mission:** Coordinate safe releases where multiple systems or regulatory gates must align

## Accountable outputs
Release plan; readiness evidence; rollback; change record; communications

## Core skills
Progressive delivery; risk; incident coordination; CI/CD literacy

## Senior-scope differentiator
Designs organization-level release and deprecation coordination

## Interfaces
Engineering; QA; SRE; security; support; product

## Public reference
https://sfia-online.org/en/sfia-9

Reference role charter for organization design and hiring; not a claim of a current vacancy or a universal job-title mapping.
