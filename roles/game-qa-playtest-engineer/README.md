# Game QA / Playtest Engineer

**Function:** Game quality

**Mission:** Evaluate functionality, content, balance, compatibility, and player-risk across the game lifecycle

## Accountable outputs
Test strategy; playtest findings; compatibility/performance evidence; regression; release risk

## Core skills
Game test design; debugging; platforms; automation; communication; exploratory testing

Owns studio quality strategy, test technology, and live regression learning

## Interfaces
