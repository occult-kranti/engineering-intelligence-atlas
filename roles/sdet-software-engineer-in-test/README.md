# SDET / Software Engineer in Test

**Function:** Quality engineering

**Mission:** Engineer test infrastructure and automation that improve delivery confidence

## Accountable outputs
Test architecture; CI suites; fixtures/data; contract/E2E tests; flaky-test reduction

## Core skills
Programming; test design; CI/CD; API/UI automation; observability

## Senior-scope differentiator
Owns test platforms and cross-team quality mechanisms

## Interfaces
Engineering; QA; platform; release; SRE
