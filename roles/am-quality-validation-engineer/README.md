# AM Quality / Validation Engineer

**Function:** Additive manufacturing

**Mission:** Establish evidence that additive parts and processes meet specified requirements

## Accountable outputs
Inspection/test plans; calibration evidence; nonconformance/RCA; traceability; qualification reports

## Core skills
Metrology; quality systems; materials testing; statistics; standards; documentation

## Senior-scope differentiator
Owns validation strategy and independent release evidence

## Interfaces
Engineering; manufacturing; regulatory; suppliers; customers
