# Systems / Economy Designer

**Function:** Game design

**Mission:** Design balanced interacting systems, progression, rewards, and virtual economies

## Accountable outputs
System/economy models; simulations; tuning rules; exploit/abuse analysis; live adjustments

## Core skills
Math/statistics; systems thinking; spreadsheets/code; player behavior; experimentation

## Senior-scope differentiator
Owns complex game-wide economy/systemic health and live balancing

## Interfaces
Game design; data; engineering; product; live ops
