# Game / Creative Director

**Function:** Game direction & production

**Mission:** Align player experience, creative vision, scope, and craft decisions across disciplines

## Accountable outputs
Creative vision; experience pillars; scope decisions; reviews; milestone quality bar

## Core skills
Game craft; leadership; communication; portfolio judgment; production and audience understanding

## Senior-scope differentiator
Owns whole-title or portfolio creative direction and cross-discipline alignment

## Interfaces
Design; engineering; art; audio; production; publishing
