# Slicing / Print-Process Engineer

**Function:** CAD & print systems

**Mission:** Translate validated geometry into reviewed machine-specific build instructions

## Accountable outputs
Slicer profiles; toolpath/build review; dry-run evidence; material/machine settings; rollback

## Core skills
Slicing; G-code/toolpaths; materials; machine behavior; testing; version control

## Senior-scope differentiator
Owns qualified slicer/process profiles and production troubleshooting

## Interfaces
AM; firmware; operations; quality; safety
