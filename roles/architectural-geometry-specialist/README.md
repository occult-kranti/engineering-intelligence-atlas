# Architectural Geometry Specialist

**Function:** Architecture & computation

**Mission:** Rationalize complex architectural geometry for structure, fabrication, assembly, and cost

## Accountable outputs
Panelization/rationalization; geometric constraints; tolerance strategy; fabrication evidence; reusable algorithms

## Core skills
Differential/computational geometry; meshes; optimization; fabrication; numerical robustness

## Senior-scope differentiator
Leads high-complexity geometry and research-to-practice translation

## Interfaces
Architecture; structure; facade; fabrication; software
