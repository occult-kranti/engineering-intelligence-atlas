# Game Designer

**Function:** Game design

**Mission:** Design mechanics, rules, loops, progression, content, and player experience against intent

## Accountable outputs
GDD/system specs; prototypes; tuning models; playtest actions; shipped mechanics

## Core skills
Game literacy; systems thinking; prototyping; communication; player psychology; iteration

## Senior-scope differentiator
Owns major systems/portfolio craft and mentors designers through evidence

## Interfaces
Product; engineering; art; UX; research; production
