# QA Analyst / Quality Engineer

**Function:** Quality engineering

**Mission:** Use risk-based evaluation to expose product and system quality risks

## Accountable outputs
Test strategy; exploratory findings; acceptance evidence; defect analysis; release-risk input

## Core skills
Test design; domain learning; risk analysis; communication; automation literacy

## Senior-scope differentiator
Shapes org quality strategy and high-risk evaluation

## Interfaces
Engineering; product; design; SRE; security; support
