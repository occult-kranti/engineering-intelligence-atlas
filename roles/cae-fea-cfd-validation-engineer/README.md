# CAE / FEA / CFD Validation Engineer

**Function:** Simulation & validation

**Mission:** Evaluate physical behavior with verified models, appropriate solvers, and empirical validation

## Accountable outputs
Analysis plan; meshes/models; verification/validation; uncertainty; engineering report

## Core skills
Mechanics/physics; numerical methods; FEA/CFD; testing; statistics; documentation

## Senior-scope differentiator
Owns high-consequence simulation strategy and independent validation

## Interfaces
Design; materials; manufacturing; safety; research
