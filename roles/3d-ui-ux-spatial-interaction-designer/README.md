# 3D UI/UX / Spatial Interaction Designer

**Function:** 3D content & spatial UX

**Mission:** Design understandable, accessible interactions for spatial, XR, and 3D interfaces

## Accountable outputs
Spatial flows; prototypes; input/depth/feedback specs; 2D fallback; accessibility/usability evidence

## Core skills
Interaction design; 3D literacy; XR ergonomics; prototyping; user research; motion/accessibility

## Senior-scope differentiator
Owns cross-product spatial UX standards and research strategy

## Interfaces
Product; XR engineering; research; accessibility; visual design
