# SOC / Security Analyst

**Function:** Security operations

**Mission:** Monitor, triage, investigate, and escalate security signals within defined scope

## Accountable outputs
Case records; triage; investigation timeline; escalation; shift/handoff notes

## Core skills
Security telemetry; networking; OS; analysis; communication; evidence handling

## Senior-scope differentiator
Leads complex investigations and improves triage/detection quality

## Interfaces
Detection; IR; threat intel; IT; engineering

## Public reference
https://niccs.cisa.gov/tools/nice-framework

Reference role charter for organization design and hiring; not a claim of a current vacancy or a universal job-title mapping.
