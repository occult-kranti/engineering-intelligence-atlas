# AM Process / Applications Engineer

**Function:** Additive manufacturing

**Mission:** Develop and stabilize reliable additive-manufacturing process parameters and applications

DOE/process maps; build files; parameter evidence; root-cause analysis; production runbooks

## Core skills
AM process physics; materials; statistics/DOE; slicing; machine operation; data analysis

## Senior-scope differentiator
Owns process qualification and cross-machine/material transfer

## Interfaces
AM engineering; operations; quality; materials; safety
