# CISO / Security Director

**Function:** Security leadership

**Mission:** Govern security risk, independence, strategy, and organizational capability

## Accountable outputs
Risk appetite; security strategy; policy; investment; board/executive reporting; assurance

## Core skills
Security governance; engineering literacy; risk; incident leadership; communication

## Senior-scope differentiator
Owns enterprise security strategy and independent challenge

## Interfaces
CTO; legal; privacy; audit; product; engineering
