# Machine Learning Engineer

**Function:** AI & ML engineering

**Mission:** Productionize model training, inference, evaluation, and monitoring

## Accountable outputs
Model pipelines/services; evaluation; deployment; monitoring; retraining runbooks

## Core skills
Python; ML/DL frameworks; software engineering; data; deployment; monitoring

## Senior-scope differentiator
Leads production ML architecture, quality, cost, and reliability

## Interfaces
Applied science; data; MLOps; backend; product
