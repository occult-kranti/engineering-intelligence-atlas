# Architectural Historian / Researcher

**Function:** Architecture & heritage

**Mission:** Produce source-grounded interpretations of buildings, traditions, texts, and cultural contexts

## Accountable outputs
Literature/source review; chronology; field/documentation analysis; publications; provenance notes

## Core skills
Historical methods; languages/sources as needed; architectural analysis; writing; research ethics

## Senior-scope differentiator
Leads cross-cultural research programs and peer/public scholarship

## Interfaces
Conservation; museums; universities; communities; design

## Public reference
https://www.icomos.org/en/charters-and-texts
