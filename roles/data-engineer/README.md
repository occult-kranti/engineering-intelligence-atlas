# Data Engineer

**Function:** Data & analytics

**Mission:** Deliver reliable, governed, documented data products and pipelines

## Accountable outputs
Batch/stream pipelines; schemas; quality SLAs; lineage; access controls; runbooks

## Core skills
SQL; programming; modeling; orchestration; distributed data; privacy; operations

## Senior-scope differentiator
Owns data-platform architecture and cross-domain data contracts

## Interfaces
Analytics; ML; backend; security; product
