**Mission:** Provide multi-team technical direction and leverage without relying on line authority

ADRs/RFCs; reference implementations; migration strategy; design review; mentoring

## Core skills
Systems design; domain depth; writing; influence; risk and tradeoff analysis

## Senior-scope differentiator
Staff aligns teams; principal shapes company/domain technical bets

## Interfaces
EM; architects; product; platform; security; SRE
