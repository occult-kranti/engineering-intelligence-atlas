# Knowledge Transfer / Learning Systems Manager

**Function:** Knowledge & capability

**Mission:** Ensure project knowledge, skills, decisions, and operational practice remain discoverable and transferable

## Accountable outputs
Knowledge architecture; onboarding/learning paths; evidence-linked repository; handoff exercises; freshness review

## Core skills
Information architecture; learning science; technical writing; research; facilitation; metrics

## Senior-scope differentiator
Owns organization-wide knowledge durability and capability-transfer programs

## Interfaces
All disciplines; docs; people; research; engineering; support
