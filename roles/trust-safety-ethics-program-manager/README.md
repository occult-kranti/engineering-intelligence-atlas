# Trust, Safety & Ethics Program Manager

**Function:** Trust & safety

**Mission:** Establish review, escalation, and learning systems for harm, abuse, integrity, and responsible operations

## Accountable outputs
Risk scenarios; policy/controls; incident review; harm metrics; transparency and remediation records

## Core skills
Risk assessment; research; policy; incident facilitation; accessibility; ethics

## Senior-scope differentiator
Owns organization-wide trust/safety strategy and independent review

## Interfaces
Legal; security; product; research; community; leadership
