# 3D Printer Embedded / Firmware Engineer

**Function:** CAD & print systems

**Mission:** Develop safe motion, sensing, control, and printer firmware/configuration

## Accountable outputs
Firmware changes; configuration review; hardware tests; safety evidence; release/rollback

## Core skills
Embedded C/C++; motion control; MCU/RTOS; thermal safety; electronics; debugging

## Senior-scope differentiator
Owns firmware/control architecture and high-risk hardware validation

## Interfaces
Hardware; print process; safety; manufacturing; quality
