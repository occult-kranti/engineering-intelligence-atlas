# Security GRC / Compliance Engineer

**Function:** Security governance

**Mission:** Make security obligations, controls, evidence, and exceptions operational and auditable

## Accountable outputs
Control map; evidence automation; risk register; assessments; remediation tracking

## Core skills
Frameworks; control design; audit evidence; automation; communication

## Senior-scope differentiator
Owns enterprise control strategy and continuous assurance

## Interfaces
CISO; legal; engineering; IT; privacy; audit
