# DfAM / Additive Manufacturing Engineer

**Function:** Additive manufacturing

**Mission:** Design parts and processes that exploit additive manufacturing while meeting engineering requirements

## Accountable outputs
DfAM analysis; material/process selection; build strategy; tolerance/post-processing plan; qualification evidence

## Core skills
Materials; AM processes; CAD; mechanics; tolerances; cost; testing; standards

## Senior-scope differentiator
Owns qualified process/part families and engineering release criteria

## Interfaces
Design; materials; manufacturing; quality; safety; supply chain
