# Mobile Engineer

**Function:** Software engineering

**Mission:** Ship reliable iOS/Android experiences under platform and store constraints

## Accountable outputs
Mobile features; offline/sync; tests; crash/performance telemetry; staged release

## Core skills
Kotlin/Swift or cross-platform; lifecycle; networking; accessibility; release engineering

## Senior-scope differentiator
Owns mobile architecture, performance, release, and cross-platform strategy

## Interfaces
Design; backend; QA; release; security; support
