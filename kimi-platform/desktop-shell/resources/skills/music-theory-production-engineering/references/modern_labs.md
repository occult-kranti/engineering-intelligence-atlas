# Modern Labs M1–M7 (explicitly modern exercises with measurable acceptance tests)

Source: `civilization_design_music_research.md` Part II §19 (2026-11-21). These are **contemporary teaching/engineering exercises** — none is a historical reconstruction. Bundled stdlib scripts and original generated fixtures (`fixtures/`) make M1 and parts of M3/M6 directly checkable offline; labs requiring external tools (browser, DAW, notation renderer, datasets) are specified with acceptance tests to run in your own environment. **No fabricated results:** if a test was not run, report it as not run.

| Lab | Skill content | Deliverable + acceptance test |
|---|---|---|
| **M1. Temperament comparator** | theory_foundations §2 | Table + audio demo: same melody in just intonation, quarter-comma meantone, Werckmeister III, and 12-TET, with cent deviations vs. a stated reference pitch. **Test:** every interval value in cents matches a computed reference table within **0.1 cent**; "Bach's temperament" phrasing prohibited without a hypothesis label. Bundled check: `python3 scripts/ratio_cents.py --self-test` (verifies the known vectors 2:1=1200.000¢, 3:2=701.955¢, 5:4=386.314¢, 81:80=21.506¢, Pythagorean comma=23.460¢, 12-TET semitone=100.000¢ to 0.001¢). |

| **M3. Notation round-trip** | theory_foundations §4 | Encode a 16-bar species-counterpoint exercise in MusicXML 4.0 + MEI; render via VexFlow/MuseScore. **Test:** schema-valid files (external XSD/DTD — not bundled); lossless pitch/duration round-trip; SMuFL-conformant rendering. ## Lab hygiene

1. Declare sample rate, tool versions, and seeds on every artifact; attach `fixtures/provenance.json`-style logs.
2. Report metric implementation with every number (mir_eval citation or pinned own implementation).
3. Label unsettled law with its status and date; never cite NO FAKES as enacted.
4. Labs that need network/external assets must state that and must not fabricate the external result.
