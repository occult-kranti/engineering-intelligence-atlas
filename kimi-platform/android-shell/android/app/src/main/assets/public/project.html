Project Mode

Run a small text-only squad (Director → Research → Build → Review) against a goal, using your own API key. Keys are encrypted with the Android Keystore and used only by native HTTPS calls to api.openai.com / api.anthropic.com.

API keys

Keys are written once to native code, encrypted with AES/GCM via the Android Keystore, and only the ciphertext is kept in app-private storage. They never enter WebView storage, logs, or events. Status is a boolean only.

Model & budgets

Model IDs come from live discovery on your provider account or from an ID you type yourself — the app ships no built-in model list.

Rates are yours to set from your provider's pricing page; 0 disables cost budgeting. Run caps are checked before every node; output tokens per call are hard-capped at 4096 by native code. Budgets stop a run — they do not retroactively undo provider charges for calls already made.

    Security & limitations
    
        
      
          
    • Keys are AES-256/GCM encrypted with a non-exportable Android Keystore key;
            only ciphertext is stored, in app-private preferences.
      • 
          
    • Known limits: the key is not bound to your lock screen (no biometric prompt on
            use); on a rooted device or compromised OS, an attacker may be able to use or
            extract decrypted secrets. A device lock and up-to-date OS are required for
            meaningful protection.
      • 
          
    • Project mode is text-only: no code execution, no repository writes, no tools.
            Provider calls are billable; there are no automatic retries.
      • 
          
    • Deleting a key is explicit and immediate. Uninstalling the app destroys the
            Keystore key and all ciphertexts.
