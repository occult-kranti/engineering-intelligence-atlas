## Evidence distinctions

Native stress tests and runtime wiring use synthetic provider results and make no billable generation calls. A real native binary, real HTTP/MCP serialization, durable leases and actual coordinator lifecycle are exercised where the environment supports them. Software WebGL evidence proves rendering, not laptop hardware performance. A finite stress suite does not prove the absence of every possible memory leak.

Local browser and tmux socket creation are restricted in this managed session. The existing GitHub Actions platform/browser gates are used for those observations; no sandbox or browser policy is bypassed.

The final evidence inventory and commit hashes will be recorded in `evidence/acceptance.json` after the final source run. External paid development calls retain their own source manifests, usage and review dispositions in `evidence/development-budget.json`.
