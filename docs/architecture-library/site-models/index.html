HOW TO READ THIS COLLECTION

Four questions for every model.

01 / What was captured?

Exterior surfaces, terrain, or a small relief fragment. Missing interiors and hidden surfaces stay missing.

02 / What was changed?

Source bytes, conversion and compression are recorded. Camera framing changes the view; it does not establish physical dimensions.

03 / What is measured?

Triangle counts describe mesh density. No model here has an independently verified metric error bound. Measurement tools remain disabled.

04 / What can be reused?

Attribution, source rights and technical game suitability are separate checks. Research-only and view-only references are not in the game asset bundle.
